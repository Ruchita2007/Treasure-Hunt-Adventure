# Treasure Hunt Adventure: The Lost Treasure

## About the Project
Treasure Hunt Adventure is a Core Java game developed
using Java Swing. The player explores a maze, collects
coins, finds a key, avoids traps, and reaches the treasure.

## Features
- Interactive game interface
- Keyboard and on-screen controls
- Coins and scoring system
- Key and treasure collection
- Traps and lives
- Smart hint system
- Multiple levels

## Technologies Used
- Core Java
- Java Swing
- Object-Oriented Programming

## How to Run
Compile:
javac -d out src/TreasureHuntAdventure.java

Run:
java -cp out TreasureHuntAdventure
